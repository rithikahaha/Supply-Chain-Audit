# Tableau Dashboard Build Guide

Data sources (generated by `python python/prepare_dashboard_data.py`):
- `data/processed/orders_clean.csv` — order-level, PII-stripped, primary source for interactive sheets
- `sql/exports/06_regional_summary.csv` — pre-aggregated, for the map if `orders_clean.csv` feels slow
- `sql/exports/07_monthly_trend.csv` — pre-aggregated, for the trend line

## Layout: one dashboard, 4 sheets + KPI row

**KPI row (top)** — text/BAN tiles, one measure each:
| Tile | Field / calc |
| :--- | :--- |
| Total Orders | `COUNT(Order Id)` |
| Overall SLA Breach Rate | `AVG(Late_delivery_risk) * 100` |
| Avg Latency Gap (days) | `AVG([Days for shipping (real)] - [Days for shipment (scheduled)])` |
| First Class Breach Rate | same as above, filtered to `Shipping Mode = First Class` |

**Sheet 1 — SLA Success by Shipping Mode** (bar chart)
Rows: `Shipping Mode`. Columns: `strict_success_rate`, `buffered_success_rate` as a dual-axis or side-by-side bar. Source: `orders_clean.csv` (compute as calculated fields) or `02_sla_performance_by_shipping_mode.csv`.

**Sheet 2 — Latency Gap Map** (filled/symbol map)
Geography: `Order Country`. Color: `avg_latency_gap` (diverging red-blue, red = later than promised). Size or tooltip: `order_volume`. Source: `06_regional_summary.csv`.

**Sheet 3 — SLA Breach Rate Over Time** (line chart)
Columns: `order_month` (or `order date (DateOrders)` truncated to month). Rows: `sla_breach_rate`. Color: `Shipping Mode`. Source: `07_monthly_trend.csv`.

**Sheet 4 — Customer Segment Impact** (bar chart)
Rows: `customer_segment` (Priority / Standard / Casual). Columns: `avg_failure_pct`. Sort descending. This is the sheet that makes the "systemic, not selective" finding visual — the three bars should look nearly identical in height.

## Filters
Add `Shipping Mode`, `Order Region`, and a date range filter on `order date (DateOrders)` to the dashboard, applied to all 4 sheets ("Apply to Worksheets: All Using This Data Source").

## Publish
1. Tableau Desktop/Public → File → Save to Tableau Public As… (needs a free [Tableau Public](https://public.tableau.com) account)
2. Rename the workbook to something recruiter-legible, e.g. "Supply Chain SLA Audit"
3. Copy the published URL and:
   - Add it to the README under **Dashboard**
   - Embed the workbook (Tableau Public gives an embed `<iframe>` snippet) in `docs/` or a GitHub Pages page if you want it viewable without leaving the repo
4. Add a static screenshot to `dashboard/screenshot.png` and reference it in the README — recruiters skimming GitHub often don't click through to live dashboards, so the image needs to sell it on its own.
